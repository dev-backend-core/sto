Комплексное бэкенд-решение для автоматизации бизнес-процессов СТО: интерактивная запись клиентов, управление рабочими сменами, распределение заказов между механиками, отслеживание жизненного цикла ремонта и аналитика сервиса.

## 📌 Ключевой функционал и логика приложения

### 🚘 Клиентский интерфейс (Front-of-House)
* **Быстрая онлайн-запись:** Клиенты выбирают необходимую услугу, дату, удобное время, вводят свои контактные данные и гос. номер автомобиля без необходимости регистрации.
* **Кастомный выбор услуг и товаров:** Привязка сопутствующих автотоваров и запчастей к конкретным работам.

### 🛠 Админ-панель (Filament v3) & Разделение ролей

#### 1. Администратор СТО:
* **Обработка заявок:** Все новые записи поступают со статусом `Новая`. Администратор подбирает свободное время, подтверждает запись и назначает ответственного механика.
* **Управление персоналом:** Создание аккаунтов для мастеров и сотрудников, гибкая настройка ролей и прав доступа.
* **Каталог и прайс-лист:** Управление услугами, ценами, категориями и привязанными товарами.
* **База клиентов и авто:** Полный архив всех клиентов, истории их обращений, номеров телефонов и гос. номеров авто.
* **Аналитика и загруженность:** Интерактивный календарь и статистика по дням недели для отслеживания пиковых нагрузок и количества авто в сервисе.

#### 2. Механик / Мастер:
* **Личный кабинет мастера:** Просмотр назначенного списка автомобилей и текущих задач.
* **Управление заказом:** Возможность принять заявку в работу или отменить её (например, если авто не приехало).
* **Фиксация данных:** При взятии машины в работу механик вносит государственный номер и VIN-код автомобиля для ведения истории обслуживания.

## 🔄 Жизненный цикл заявки (State Machine)
```text
[ Заявка клиента ] ──► ( Статус: Новая )
                            │
                            ▼  (Администратор назначает время и механика)
                   ( Статус: Подтверждена )
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
( Принято механиком )            ( Отменено / Не приехал )
 Статус: В работе                 Статус: Отменена
 [Ввод VIN и гос. номера]

### 🚀 Быстрый запуск проекта в Docker (Laravel Sail)
Клонировать репозиторий:Bashgit clone [https://github.com/dev-backend-core/sto.git](https://github.com/dev-backend-core/sto.git)
cd sto
Настроить переменные окружения:Bashcp .env.example .env
Запустить контейнеры Docker:Bash./vendor/bin/sail up -d
Установить зависимости и выполнить миграции с сидами:Bash./vendor/bin/sail composer install
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate --seed
Приложение будет доступно по адресу: http://localhost
